# Техподдержка Одинцовского техникума

Локальный сайт для отметки присутствия техников и обработки заявок преподавателей.

## Запуск

1. На компьютере техника должен быть установлен Python 3.
2. Запустите `start.bat` двойным щелчком или выполните `python app.py`.
3. Откройте адрес, который напечатает сервер, например `http://localhost:8081`.
4. Узнайте локальный IP компьютера командой `ipconfig`. На компьютерах преподавателей откройте `http://ЛОКАЛЬНЫЙ_IP:ВЫБРАННЫЙ_ПОРТ`, например `http://192.168.1.20:8081`.

Сервер автоматически получает свободный порт от Windows и слушает внутреннюю сеть через адрес `0.0.0.0`. Используйте IP и порт из сообщения запуска. Если другой компьютер показывает ошибку `502`, отключите прокси для локальных адресов или добавьте IP компьютера-сервера в исключения прокси: локальный адрес должен открываться напрямую, без прокси. Если Windows Firewall спросит разрешение для Python, разрешите доступ для частной сети техникума.

## Работа с сайтом

- Режим «Преподаватель» позволяет видеть присутствие и отправлять заявки.
- Режим «Техник» доступен после входа по учетной записи, добавляет изменение присутствия и рабочего статуса, а также перевод заявок между состояниями «Новая», «В работе» и «Выполнено».
- Отдельная страница `/dispatcher.html` предназначена для распределителя: она показывает все заявки, текущие статусы и занятость команды, а также позволяет назначать исполнителя.
- В кабинете техника отображаются только назначенные ему заявки.
- В выполненной заявке отображается исполнитель, а в кабинете техника показывается количество выполненных им заявок за сегодня.
- В кабинете техника можно обрабатывать только назначенные ему заявки, менять их статус, добавлять комментарии и просматривать историю изменений.
- Администратор может редактировать имя, логин и пароль любого техника.
- Кабинет техника показывает количество новых заявок, заявок в работе, выполненных за сегодня и выполненных за текущий месяц.
- Администратор входит через режим «Администратор» с логином `admin` и паролем `Admin123!`, управляет техниками и расписанием, создаёт резервные копии и скачивает заявки в CSV.
- Распределитель входит на странице `/dispatcher.html` с логином `dispatcher` и паролем `Dispatcher123!`.
- Если статус техника не обновлялся 8 часов, он автоматически скрывается и отображается как «Отсутствует».
- Выполненные заявки после наступления следующего дня автоматически переносятся в отдельный файл `archive.json` и исчезают из текущего списка сайта.
- Интерфейс адаптирован для телефонов, поддерживает тёмную и светлую темы, выделяет срочные заявки цветом и показывает счётчик новых заявок.
- Данные обновляются автоматически без перезагрузки страницы, а новые заявки и изменения статусов показываются уведомлением. После обновления страницы активный кабинет сохраняется.
- Все изменения сохраняются в `data.json` рядом с сервером и видны другим открытым страницам после обновления.

Учетные записи техников настроены в `app.py`. Для реальной эксплуатации можно следующим шагом добавить журнал действий и резервное копирование заявок.
